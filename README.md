# Pathfinder Market

Справочник снаряжения, совместимый с настольной ролевой игрой Pathfinder 1e. Приложение позволяет просматривать оружие, фильтровать и сортировать его, а также рассчитывать стоимость магических улучшений.

## Возможности

- Список всего оружия из Pathfinder 1e с характеристиками
- Поиск, фильтрация по типу, категории и источнику
- Сортировка по цене и алфавиту
- Экран улучшения оружия: masterwork, магические бонусы и особые свойства с подсчётом итоговой стоимости

## Технологии

- Kotlin
- Jetpack Compose + Navigation
- Hilt
- Room
- Retrofit + Gson

## Источник данных

Данные о снаряжении предоставлены API сайта [pathfinder.family](https://pathfinder.family).
